# 대구 영유아 돌봄 인프라 분석

대구 영유아(만 0~5세) 가정을 위해 어느 지역이 돌봄·체육 인프라가 부족한지를
공공데이터로 정량화하고, "시설이 없는 곳"과 "시설은 있는데 이용이 저조한 곳"을
구분해내는 미스매치 진단 프로젝트입니다.

- 데이터 확보·전처리: `pipeline/` (pandas)
- 지수 산출·회귀분석: `analysis_lib.py`, `ua_entropy_composite_index.py`, `ua_regression_analysis.py`
- 웹 서비스: `app/` (FastAPI) + `static/` (프런트엔드)

---

## 2. 데이터 파이프라인 (pandas)

원천 공공데이터(행안부 인구, 유치원 공시정보, 어린이집 표준데이터, 체육시설
인허가데이터, 학원교습소정보, 국토부 실거래가, KOSIS 사회지표)를 좌표
기반으로 읍면동 단위에 결합합니다. 순서와 각 단계의 역할은 위 표를 참고하세요.

핵심 설계는 기획서 그대로입니다.

- **수요** = 영유아 인구수 (재원수로 잡으면 "시설 없는 곳 = 수요 없음"이 되는 순환논리를 피하기 위함)
- **공급** = 어린이집·유치원 정원 (+ 참고용으로 학원 정원)
- **실현** = 어린이집·유치원 현원

세 지표를 조합해 미스매치 4유형(물리적부족 / 질적미스매치 / 이중취약 / 양호)과
완전공백·판정불가를 분류합니다. **군위군은 2023년 편입된 농촌지역으로 인프라
자체가 도심과 차원이 달라(커버율·체육밀도가 대부분 0), 그대로 포함하면 지수
하위권을 독점하며 중앙값 기준선을 왜곡합니다.** 그래서 지수 산출·회귀분석
전 단계에서 도심 7개 구 기준으로 계산하고, 군위군은 "인프라 사각지대
극단사례"로 별도 표기만 합니다 (제외가 아니라 분리).

## 3. 분석 모델

### 6장 — 엔트로피 가중치 종합지수 (`analysis_lib.compute_entropy_composite`)

전체_커버율(공급 충분도)과 체육밀도(유아 1천명당 체육시설수) 두 지표를
Min-Max로 0~1 정규화한 뒤, **엔트로피 가중치**로 합칩니다.

> 어떤 지표가 지역 간에 별 차이가 없으면(다 비슷하면) 그 지표는 "구별력"이
> 없다고 보고 가중치를 낮추고, 반대로 지역 간 편차가 큰 지표는 가중치를
> 높입니다. 분석가의 주관("이게 더 중요해 보인다")이 개입하지 않는다는 게
> 핵심 장점입니다.

산출 결과 전체_커버율 71%, 체육밀도 29%로 가중되었고, 이 결과를 단순평균
가중치와 비교했을 때 상관계수 0.94(순위상관 0.97)로 방법을 바꿔도 결론이
크게 달라지지 않음을 확인했습니다. 가중치를 ±20% 무작위로 흔드는 민감도
분석(200회)에서도 평균 순위상관 0.999로, 종합지수가 안정적임을 검증했습니다.

### 7장 — 회귀분석 (`analysis_lib.compute_regression_models`)

사분면 분석이 메인이고, 회귀분석은 **"우리 지수가 임의가 아님을 증명하는
검증 도구"**입니다. 예측이 목적이 아니라 계수의 유의성으로 영향력을
규명하는 것이 목적입니다.

- **모델 A** — `전체_충원율 ~ 영유아인구_0_6세 + 체육시설수 + 고용률`
  돌봄시설 이용에 영향을 주는 요인 검증. (맞벌이비율의 동 단위 데이터가
  없어 구 단위 고용률을 근사치로 사용 — 한계로 명시)
- **모델 B** — `평균제곱미터당가격_만원 ~ 체육시설수 + 학원정원합계 + 전체_커버율 + 수성구더미`
  집값에 인프라가 실제 영향을 주는지, 그리고 그 프리미엄이 인프라 때문인지
  "수성구라는 학군 지역 자체" 효과인지 더미변수로 분리.

결과는 `python ua_regression_analysis.py` 실행 시 `data/daegu_regression_result.txt`에
계수·표준화계수·p-value·VIF(다중공선성)까지 저장됩니다.

## 4. 실행 방법

```bash
pip install -r requirements.txt

# (선택) 지수/회귀 CLI를 따로 돌려서 결과 파일만 뽑아보고 싶을 때
python ua_entropy_composite_index.py
python ua_regression_analysis.py

# 웹 서버 실행
uvicorn app.main:app --reload --port 8000
# 브라우저에서 http://127.0.0.1:8000 접속
```

## 6. 한계 및 주의사항 (발표 시 명시할 것)

- 미스매치 원인(품질/안전/접근성 등)은 정량 데이터로 단정할 수 없습니다.
  "충원율이 낮은 질적 미스매치 지역이 관찰된다"까지만 말할 수 있습니다.
- 모델 A의 '고용률'은 구 단위 통계로, 원래 설계된 동 단위 맞벌이비율의 근사치입니다.
- 학원 데이터는 현원 정보가 없어 커버율(공급)에만 반영되고 충원율에는 반영되지 않습니다.
- 군위군은 성격이 다른 지역이라 별도 처리했으며, 제외가 아니라 "극단사례"로 다룹니다.
- 회귀분석은 상관관계 확인 도구이며 인과관계를 증명하지 않습니다.

## 7. 평가 기준 대응

- **주제 적절성**: 실제 공공정책 의사결정(보육 인프라 배치)에 바로 쓸 수 있는 진단 지표
- **데이터 수집·활용**: 7종 공공데이터(인구/유치원/어린이집/체육시설/학원/부동산/KOSIS)를 좌표 기반으로 통합
- **분석·AI 활용**: Min-Max 정규화, 엔트로피 가중치, 다중회귀(OLS), VIF 다중공선성 점검, 민감도 분석
- **결과 완성도·실용성**: FastAPI 기반 인터랙티브 대시보드로 결과를 바로 조회·필터링 가능
- **GitHub 관리**: 파이프라인/분석/서빙 계층 분리, 공통 로직 모듈화(analysis_lib.py)로 중복 제거

## 8. 팀원 파일 병합 내역

팀원이 별도로 작업한 4개 파일을 검토해 아래와 같이 정리했습니다.

| 파일 | 처리 |
|---|---|
| `ua_regression_and_quadrant.py` | **병합함.** 사분면 산점도 PNG 생성 로직을 `analysis_lib.generate_quadrant_chart()`로 가져왔습니다(엔트로피 지수 기준으로 통일). 회귀분석 변수 중 `합계출산율_2025`를 모델 A/B 각각에 추가 테스트한 결과, 모델 A는 개선 없음(R² 변화 없음, p=0.92)이라 제외했고 모델 B는 유의미하게 개선(R² 0.439→0.470, p=0.005, VIF<2)되어 채택했습니다. |
| `calculate_mismatch_index.py` | 미완성 초안(인구 결합 전 단계)으로, 이미 완성된 `pipeline/` 결과물로 대체되어 폐기했습니다. |
| `checking.py` | 체육시설 주소 정규식 파싱 초안으로, 더 정확한 `pipeline/ua_add_sports_facility.py`(카카오 좌표 역지오코딩 방식)로 이미 대체되어 폐기했습니다. |
| `main.py` (+ `backend/collectors/`) | 완전히 별개 작업입니다. "다함께돌봄센터"(제3의 돌봄시설 유형) 데이터를 공공데이터포털 API로 수집하는 스크립트로, 현재 미스매치 분석에는 아직 반영되지 않았습니다. 데이터 수집이 끝나면 `pipeline/`에 새 결합 단계로 추가하는 것을 권장합니다 (이 폴더명 "다함께돌봄센터_수집기"의 유래로 보입니다). |

새로 생성되는 산출물: `data/daegu_quadrant_chart.png` (인프라지수 vs 집값 사분면 산점도, `python ua_entropy_composite_index.py` 실행 시 자동 생성)

## 9. 인구이동(MDIS) 인사이트 통합

팀원이 만든 인사이트 리포트(통계청 국내인구이동통계 마이크로데이터 2023~2025년,
대구 관련 940,045건 분석)를 검토한 결과, **정원·현원 수치가 본 프로젝트의
`통합_정원`/`통합_현원`(유치원+어린이집, 학원 제외)과 성내3동·고성동·범어1동·
평리5동 4개 동 전부 소수점까지 정확히 일치**함을 확인했습니다. 같은 최종
데이터 위에 인구이동 데이터를 추가 결합해 만든 분석입니다. 또한 이 리포트의
"행정동 142개"는 본 프로젝트에서 군위군(8개 면)을 제외한 도심 7개 구 동
수와도 정확히 일치합니다.

`analysis_lib.MIGRATION_INSIGHTS`에 3가지 인사이트를 반영했고, `/api/insights`로
제공하며 대시보드에도 표시됩니다.

- **인사이트 1**: 영유아 동반 이주 가구의 47.8%가 "주택"을 주된 사유로 꼽음(전체
  이동은 27.8%) — 그런데 순유입 1~4위 동네가 동시에 대구 최저 커버율 지역
- **인사이트 2**: 정책 우선지역 4곳(성내3동·고성동·범어1동·평리5동) — 반경
  커버율(2SFCA, 1km)로 보정해도 전부 100% 미만
- **인사이트 3**: 정원이 남는 39개 동 중 28개는 "유출 심화"(감축 가능), 11개는
  "유입·보합"(감축 금지) — 총량이 아닌 배치 교정이 필요

**한계**: 인구이동 원자료(MDIS)와 2SFCA 반경 커버율 계산 자체는 이 코드베이스에
포함되어 있지 않습니다(팀원이 별도 수행). 위 수치는 결과값을 그대로 옮긴 것이며,
원자료를 공유받으면 `pipeline/`에 새 단계로 추가해 150개 전체 동에 대해
동일하게 계산할 수 있습니다.

## 10. 파일명 관련 참고사항

데이터 파일명은 모두 영문(`daegu_final_dataset.csv` 등)으로 통일했습니다. 이전
버전은 파일명에 한글이 섞여 있어, Windows 기본 압축 풀기 프로그램이 일부
파일을 에러 메시지 없이 조용히 건너뛰는 문제가 있었습니다(특히 파일명이 길고
한글+언더스코어가 섞인 경우). 코드나 문서 파일명은 한글이어도 문제없지만,
zip으로 압축·해제하는 데이터 파일명은 영문을 권장합니다.
